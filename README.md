# Definitionless

The Definitionless homepage and Seven Sunrises run in the same application in the
[Seven Sunrises repository](https://github.com/thecanonwing-arch/seven-sunrises).
This repository retains the original portal draft.

## Run the local review

With Bun installed and access to the private Seven Sunrises repository, run:

```sh
git clone --branch preview/approved-homepage https://github.com/thecanonwing-arch/seven-sunrises.git
cd seven-sunrises
bun install --frozen-lockfile
bun run dev
```

Open the local URL printed by the dev server. Choose the yellow **Program-Breaking Kit**
button and submit `rebel@example.com`. Open the kit, download the review excerpt, and
continue to Sunrise One. The written course is also available directly.

The local signup uses reserved test addresses and delivers the kit in the browser.
The original portal draft and this review handoff can be read without running the application.
