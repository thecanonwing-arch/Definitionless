# Definitionless

This repository preserves the original Definitionless portal handoff. The homepage
and Seven Sunrises run in the same application in the private
[Seven Sunrises repository](https://github.com/thecanonwing-arch/seven-sunrises).

## Run the local review

With Bun installed and access to the private repository, follow the setup steps in
the [author review](https://github.com/thecanonwing-arch/seven-sunrises/blob/review/canon-website-completion/docs/review/canon-website/REVIEW.md).

Open the local URL printed by the dev server. Choose **FREE PROGRAM BREAKERS' KIT**,
follow **Report your findings**, and submit a fictional observation. The browser
builds a Field Guide and a Field Day immediately. Use **Keep a copy of this dispatch**
to download the Kit, then continue to Seven Sunrises.

The optional test outbox accepts reserved `example.com` addresses. It produces
a sample message for review. The written Seven Sunrises is available directly.
